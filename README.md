# 🌍 Wanderlust - Explore & List Your Favorite Destinations

**Wanderlust** is a full-stack web application inspired by Airbnb, where users can explore travel listings, add their own places, and leave reviews. Built using EJS for the frontend, Node.js and Express.js for the backend, and MapTiler for visualizing location data.

---

## 🔧 Tech Stack

- **Frontend:** EJS templating, HTML, CSS, Bootstrap
- **Backend:** Node.js, Express.js
- **Authentication:** Passport.js with session-based login
- **Database:** MongoDB with Mongoose
- **Maps:** MapTiler for location visualization

---

## ✨ Features

- 🧭 **Browse Listings:** Discover travel destinations listed by other users  
- ➕ **Add Listing:** Sign up and post your own travel stay or location  
- 📝 **Review System:** Leave reviews and ratings for other listings  
- 🗺️ **Interactive Map:** View each listing’s location using MapTiler  
- 🔐 **Authentication:** Secure user login/signup with Passport.js and sessions  

---

## 🚀 Getting Started

### 1. Clone the Repository
    git clone https://github.com/Shrutivk12/Project_Wanderlust.git
    cd Project_Wanderlust
    
### 2. Install Dependencies
    npm install
    
### 3. Set Up Environment Variables - Create a .env file in the root with the following variables:
    CLOUD_NAME=cloudinary_name
    CLOUD_API_KEY=your_api_key
    CLOUD_API_SECRET=your_api_secret
    MAP_TOKEN=your_maptiler_api_key
    ATLASDB_URL=your_mongodb_url
    SECRET=your_sessions_secret
